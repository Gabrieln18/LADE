> **Writer:** reviewer only, after a `standard` review. **Mode:** append-only; existing entries are never edited or deleted by agents.
> One entry, one lesson, at most ~10 lines. Write only when the failure is recurring, non-obvious or caused a `REWORK` (`agents/reviewer/references/review-principles.md` §6).

## Entry format

```
### L-NNN · <one-line lesson>
- **Date:** YYYY-MM-DD
- **Task:** LADE-YYYYMMDD-NNN
- **Affects:** <agent | workflow | skill | reference | policy>
- **Observed:** <what happened, with the artifact or diff location>
- **Cause:** <the reasoning error, not the symptom>
- **Rule:** <the imperative rule that prevents recurrence>
- **Promoted to:** <convention | skill | policy | reference | not yet>
```
